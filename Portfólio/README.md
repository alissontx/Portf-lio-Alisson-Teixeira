## Antes de publicar
Revê os textos biográficos e os projetos para garantir que representam exatamente o que queres tornar público. Acrescenta links individuais para demonstrações e códigos dos projetos quando estiverem prontos.

## Publicar no GitHub Pages
1. Cria um repositório chamado `alissontx.github.io`, caso ainda não exista.
2. Envia `index.html`, `style.css`, `script.js` e a pasta `assets`.
3. Em Settings → Pages, seleciona a branch `main` e a pasta `/ (root)`.
4. O site ficará disponível em `https://alissontx.github.io`.

## Versão 4.0 — refinamentos
- Sistema responsivo consolidado num único conjunto de breakpoints.
- Ajustes específicos para telemóveis estreitos, tablets, notebooks, desktops e ecrãs ultrawide/TV.
- Menu adaptativo com fecho por Escape, clique fora e redimensionamento.
- Melhorias de foco por teclado, imagens e comportamento em orientação horizontal.
- CSS organizado para reduzir conflitos entre regras antigas e novas.

## Validação recomendada
Testar visualmente em 320, 360, 390, 480, 768, 1024, 1366, 1440, 1920 e 2560 px. A presença de breakpoints não substitui a validação em dispositivos e navegadores reais.
